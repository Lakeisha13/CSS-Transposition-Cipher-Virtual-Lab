Transposition Cipher Aim

Aim

Fundamental transposition cryptography experiment

Experiment Aim

  • To study and observe position-based rearrangement (permutations) in classical cryptography using the Rail Fence Cipher (keyless transposition) and the Columnar Transposition Cipher (keyed transposition).
  • To demonstrate how inverse permutations restore the original plaintext during decryption.

Objective

Learning outcomes for the transposition cryptography experiment

Learning Objectives

  • Understand the distinction between Substitution (altering symbol identity) and Transposition (altering symbol position).
  • Observe the zig-zag row traversal and its cycle period: T = 2(r - 1).
  • Learn how keyword alphabetical ranking dictates column extraction order.
  • Construct an uneven final row without adding dummy characters, then reconstruct the original column lengths during decryption.
  • Observe the forward permutation pi(i) and inverse pi^-1(j).

Theory

Mathematical foundation of permutation-based ciphers

1. Transposition Ciphers & Permutation Theory

In a transposition cipher, message symbols are unchanged but their positions are permuted. For a message of length n, encryption is a bijective mapping:

pi : {0, 1, ..., n-1} → {0, 1, ..., n-1}   such that   C[pi(i)] = P[i]

Decryption uses the inverse permutation pi^-1:

P[i] = C[pi(i)] ⇔ P[pi^-1(j)] = C[j]

2. Rail Fence Cipher

Characters are written in a zig-zag pattern across r horizontal rows. The ciphertext is produced by reading rows from top to bottom.

Cycle Period: One full oscillation spans 2(r - 1) characters.
Row Assignment: Row for index i oscillates between 0 and r-1.

Example: HELLOWORLD, 3 Rows

Row 1: H . . . O . . . L .  (Indices 0, 4, 8)
Row 2: . E . L . W . R . D  (Indices 1, 3, 5, 7, 9)
Row 3: . . L . . . O . . .  (Indices 2, 6)
Ciphertext: H O L E L W R D L O

3. Columnar Transposition

Plaintext is written row-by-row into a grid beneath a keyword of length m. Columns are read vertically in alphabetical order of the keyword letters.

Key Ranking: ZEBRA → A(1), B(2), E(3), R(4), Z(5).
Lab Keyword Rule: This simulator keeps only the first occurrence of each keyword letter; BALLOON becomes BALON. This is a deduplicated-key variation.

Uneven Final Row

When the message length is not a multiple of the keyword length, the final row remains incomplete. No dummy X characters are inserted. During decryption, the simulator calculates the original length of each column.

Procedure

Systematic step-by-step cryptographic procedures

Rail Fence

Encryption

  1. Remove spaces and symbols, and write all letters in uppercase.
  2. Write the letters diagonally down and up across the given number of rows.
  3. Repeat this pattern until all letters are written.
  4. Read the letters row by row to get the ciphertext.

Decryption

  1. Mark the positions where the letters were written in the zig-zag pattern.
  2. Fill the marked positions with ciphertext letters, row by row.
  3. Follow the zig-zag pattern to read the letters in the correct order.
  4. Join the letters to get the original plaintext.

Columnar Transposition

Encryption

  1. Remove spaces and symbols, and write all letters in uppercase.
  2. Remove repeated keyword letters, keeping the first occurrence (for example, BALLOON becomes BALON).
  3. Write the resulting keyword above the plaintext in a table.
  4. Arrange each plaintext character once, row by row, under the keyword. Leave unused cells in the final row blank.
  5. Read the columns in alphabetical order of the remaining keyword letters to get the ciphertext.

Decryption

  1. Remove repeated keyword letters, keeping the first occurrence, then rank the remaining letters alphabetically.
  2. Calculate the original length of each column from the ciphertext length and keyword length.
  3. Place each ciphertext segment into its corresponding column in ranked order.
  4. Read the reconstructed table row by row to recover the original plaintext.
